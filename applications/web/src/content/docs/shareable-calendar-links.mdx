A shareable calendar link is one link carrying the calendars you pick. Anyone can subscribe to it from Google Calendar, Outlook or Apple Calendar and see those calendars, refreshed by their app on its own schedule.

The dashboard calls these links **iCal Feeds**, and each feed is one link with its own calendars and settings. Unlike [sending events to another calendar](/docs/sending-events-to-another-calendar), a link copies nothing into anyone's calendar. Delete the feed and the link stops working.

## What the link carries

**Calendars** picks which of your calendars the link includes. Only calendars Keeper.sh can read are listed.

**Feed Settings** decides how much of each event the link gives away:

- **Include Event Name** — off by default, so every event carries a stand-in title
- **Event Name** — the stand-in title, "Busy" by default; `{{event_name}}` and `{{calendar_name}}` fill in the real title or the calendar's name
- **Include Event Description** and **Include Event Location** — both off by default

**Event Filters** leaves whole categories out of the link: all-day events, and on Google calendars, focus time and out-of-office blocks.

Feed settings and filters are Pro features. On Free the link runs on the defaults, which are the private ones: times only, every event titled "Busy".

## Checking what a link shares

Under the link, Keeper.sh states in plain words what it currently shares — "This link shares event times only", or times and names, and so on. The line is written from the live settings, so read it before handing the link to anyone.

## Anyone with the link can read it

The link carries no sign-in, so whoever holds it can subscribe. Treat it like a password.

If a link has spread further than you meant, delete the feed. Subscribed calendar apps stop receiving events, and a new feed comes with a new link.

## How many links you get

Free includes one. Pro is unlimited, so a colleague can hold a times-only link while your own phone gets a fuller one. [Plans and limits](/docs/plans-and-limits) has the rest of the counts.
