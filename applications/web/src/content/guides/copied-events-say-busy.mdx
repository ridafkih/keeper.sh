Keeper.sh hides titles, notes and locations by default, so events arriving without them means a privacy setting is doing its job. A copied event shows the name of the calendar it came from; an event seen through a shareable link says "Busy". Each is changed in a different place.

## First, which one are you looking at?

A **copied event** sits in a real calendar you connected, because a [connection](/docs/sending-events-to-another-calendar) put it there. A **subscribed link** is a calendar your app reads from a Keeper.sh link. If you or someone else added the calendar by pasting a link, it is a link.

## If it is a copied event

Copies take their stand-in title from the **Event Name** field, which starts as the name of the calendar they came from. Notes and locations are left behind entirely.

To let the real titles through:

1. Open the calendar the events come from in the dashboard.
2. Turn on **Sync Event Name**.
3. Wait for the next update — within 30 minutes on Free, within a minute on Pro.

**Sync Event Description** and **Sync Event Location** on the same calendar do the same for notes and meeting links. All three need Pro. [What a copied event shows](/docs/what-a-copied-event-shows) covers them in full.

## If it is a subscribed link

A shareable link shares event times only until you say otherwise. Titles, notes and locations are all off, and the stand-in title is "Busy". The line under the link states exactly what it currently shares.

To share more, open the link's page and turn on **Include Event Name**, **Include Event Description** or **Include Event Location** under **Feed Settings**. These need Pro. [Shareable calendar links](/docs/shareable-calendar-links) covers the rest.

Changing a link changes it for everyone subscribed to it. If only some people should see titles, make a second link and hand each person the right one. The [share your busy times](/recipes/share-when-you-are-busy) recipe builds exactly that.

## Turned the setting on and nothing changed?

- **You are looking at a different calendar than you set up.** Settings live per calendar, so an account with several calendars can have the right settings on the wrong one.
- **You changed it a moment ago.** Existing copies are corrected on the next update, not instantly — within 30 minutes on Free, within a minute on Pro.
